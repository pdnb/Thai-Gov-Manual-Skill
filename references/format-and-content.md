# รูปแบบเอกสารและโครงสร้างไฟล์เนื้อหา

## รูปแบบที่ build-docx.mjs สร้างให้ (แนวหนังสือราชการ / คู่มือหน่วยงานรัฐ)

| รายการ | ค่า |
|---|---|
| ฟอนต์ | TH Sarabun New ทั้งเล่ม (ต้องติดตั้งในเครื่องที่เปิดไฟล์) |
| ขนาด | เนื้อความ 16pt · หัวข้อย่อย (x.y.z) 16pt หนา · หัวข้อ (x.y) 18pt หนา · ชื่อบท 20pt หนา กึ่งกลาง 2 บรรทัด ("บทที่ n" / ชื่อบท) |
| กระดาษ / ขอบ | A4 · ซ้าย 3 ซม. ขวา 2 ซม. บน 2.5 ซม. ล่าง 2 ซม. (พื้นที่เนื้อหา 16 ซม. = 9071 DXA) |
| เลขหน้า | ปกไม่มีเลข · ส่วนนำ ก ข ค · เนื้อหา 1 2 3 · กึ่งกลางด้านบน |
| ส่วนนำ | ปก → การควบคุมเอกสาร (ประวัติฉบับ + ช่องลงนาม ผู้จัดทำ/ผู้ตรวจสอบ/ผู้อนุมัติ) → คำนำ → สารบัญ → สารบัญภาพ → สารบัญตาราง |
| คำบรรยาย | "ภาพที่ บท-ลำดับ" ใต้ภาพ กึ่งกลาง · "ตารางที่ บท-ลำดับ" เหนือตาราง (นับใหม่ทุกบท, ภาคผนวกใช้ ก/ข/ค) |
| ขั้นตอน | รายการ 1. 2. 3. เริ่มนับใหม่ทุกกลุ่ม — ต้องตรงกับหมายเลขแดงบนภาพก่อนหน้า |
| หมายเหตุ | กล่องพื้นเหลืองอ่อน เส้นซ้ายสีส้ม ขึ้นต้น "หมายเหตุ" |
| ท้ายกระดาษ | ชื่อคู่มือ + ฉบับที่ ตัวเล็กชิดขวา |

ข้อความไทยถูกแทรก U+200B ระหว่างคำ (Intl.Segmenter) เพราะ Word ที่ไม่ได้ติดตั้ง Thai proofing จะตัดบรรทัดได้เฉพาะที่ช่องว่าง ทำให้ย่อหน้ายืด/ขาดผิดที่ อย่าเอาออก และอย่าใช้ thaiDistribute (ถ่างตัวอักษร) — ใช้ justified

ขนาดภาพในเล่ม: ภาพเต็มจอ (CSS 1440px) กว้าง 15 ซม. · ภาพที่ตัดเฉพาะส่วนกว้าง ≤ 800px ย่อน้อยลง (×0.62) · แถบยาวเตี้ย (< 260px) ×0.6 · สูงเกินจำกัดที่ ~21 ซม. · ภาพมีกรอบเทาบาง

## content.mjs

```js
export const meta = {
  system: 'ชื่อระบบภาษาไทย', systemEn: 'ชื่อภาษาอังกฤษ',
  title: 'คู่มือการใช้งานระบบ', subtitle: 'สำหรับผู้ใช้งาน',
  org: 'หน่วยงานผู้จัดทำ', university: 'ชื่อองค์กร', version: '1.0',
  dateTh: 'พฤศจิกายน 2569', yearTh: '2569',
};
export const control = [['1.0', 'พฤศจิกายน 2569', 'จัดทำฉบับแรก ...']];   // ประวัติการปรับปรุง
export const preface = ['ย่อหน้าคำนำ 1', 'ย่อหน้า 2'];
export const chapters = [{ title: 'ชื่อบท', blocks: [/* ดูด้านล่าง */] }];
export const appendices = [{ title: 'ข้อความแจ้งเตือนและปัญหาที่พบบ่อย', blocks: [] }];
export const extraCaptions = { '2-1': 'คำบรรยายของภาพที่ไม่ได้มาจาก shot()' };
```

ชนิดของ block:

| block | ผลลัพธ์ |
|---|---|
| `{ h2: 'หัวข้อ' }` / `{ h3: '...' }` | หัวข้อ x.y / x.y.z (ใส่เลขให้อัตโนมัติ, x.y เข้าสารบัญ) |
| `{ p: '...' }` | ย่อหน้า ย่อบรรทัดแรก |
| `{ steps: ['...', '...'] }` | รายการเลข 1. 2. … (ตรงกับหมายเลขบนภาพ) |
| `{ bullets: [...] }` | รายการจุด |
| `{ note: '...' }` | กล่องหมายเหตุ |
| `{ fig: '3-4' }` | ภาพ `<imagesDir>/3-4.png` + คำบรรยายจาก manifest.json |
| `{ figs: ['1-7', '1-8'] }` | สองภาพเคียงกัน (เช่น มือถือ, ตัวอย่างหน้า error) |
| `{ table: { caption, widths: [dxa...รวม 9071], head: [...], rows: [[...]] } }` | ตารางมีหัวสีเทา ทำซ้ำหัวเมื่อขึ้นหน้าใหม่ |

id ของภาพเป็นแค่ชื่อไฟล์ — เลข "ภาพที่" ในเล่มนับตามลำดับที่ปรากฏในบทนั้น จึงย้ายภาพข้ามบทได้โดยไม่ต้องเปลี่ยนชื่อไฟล์

## โครงเล่มคู่มือผู้ใช้ที่แนะนำ

1. บทนำและการเริ่มต้นใช้งาน — วัตถุประสงค์ ขอบเขต (ตารางกลุ่มผู้ใช้ ↔ บท) อุปกรณ์ที่ใช้ได้ การเข้าสู่ระบบ ส่วนประกอบหน้าจอ เมนูบัญชี มือถือ
2. ภาพรวมของระบบ — แผนภาพขั้นตอน (เรนเดอร์จาก HTML ดู example-sru/diagram.mjs) ตารางสถานะ
3. … บทละหนึ่งบทบาท เรียงตามลำดับที่งานไหลผ่านระบบ
4. ภาคผนวก — ข้อความแจ้งเตือนและวิธีแก้ (+ ตัวอย่างหน้า 403/404/สรุปข้อผิดพลาดฟอร์ม) · อภิธานศัพท์ · ช่องทางติดต่อ

คู่มือผู้ดูแลระบบทำเป็นเล่มแยกด้วย builder เดียวกัน (content คนละไฟล์)
